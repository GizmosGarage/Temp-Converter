# Temperature Converter

I am learning how to program with Python by building small projects rather than following lessons.

This program convert temperatures between Fahrenheit and Celsius.

## What I'm practicing

- Functions
- User input
- Conditional statements
- String indexing and slicing
- Type conversion

## How to use it

Enter a temperature ending in either 'f' or 'c', and the program converts your input.

Example:

```text
32f
100c
```text

## Run

python3 Temp_Convert.py
